# Transition Watak Manhwa v1
Buka index.html untuk tiga demo. Pilih watak, tekan Main semula. Slider membolehkan semakan setiap detik. Jeda dan mod gerakan minimum disediakan.

1. Jurucerita: masuk, buka manuskrip, manuskrip berkembang, keluar.
2. Pengembara: jalan, capai, genggam, tarik halaman, keluar.
3. Pendekar: muncul di tengah, bersedia, lompat, genggam zip, tarik sambil mendarat, skrin terbuka, hilang.

PNG asal telus: enam pose setiap watak. Gerakan ialah interpolasi posisi dengan pertukaran pose, bukan animasi video frame-by-frame. Manuskrip yang berkembang, kertas dan zip dilukis dalam HTML/CSS/canvas. Tiada audio dalam demo. MCQ tidak menjalankan timer kelas; ia paparan tujuan transition sahaja. Belum diintegrasi dengan lesson penuh.
